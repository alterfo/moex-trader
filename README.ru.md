# MOEX Trader (Approximate)

Русский перевод: [README.ru.md](README.ru.md). Этот файл (английский) — канонический.

> Источник истины и направление: [docs/VISION.md](docs/VISION.md).

Трейдер на Go для инструментов MOEX. Собирает рыночные данные и новости, строит вектор из 28 признаков, получает сигнал `BUY`/`SELL`/`HOLD` от чисто-Go модели (таблица оценок ridge, ансамбль LightGBM + XGBoost + логистика или объединённая логистическая регрессия), пропускает его через риск-гейт и исполняет — сначала в paper-режиме, затем в песочнице T-Bank. Каждый шаг пишется в SQLite как событие аудита. Перед стартом живого цикла `cmd/trader` проигрывает **ту же модель и конфигурацию** в preflight-бэктесте и отказывается стартовать при убытке или недоступной истории.

Реальные деньги намеренно отключены: `cmd/trader` отказывается работать с не-песочным счётом.

## Быстрый старт

```sh
go build ./...
make check                                              # go test + go vet
go run ./cmd/trader -config config.sandbox.yaml         # T-Bank sandbox (needs .env tokens)
go run ./cmd/backtest -signal-source=ensemble -ensemble-path ensemble_model.json
```

Полный список команд, таблица конфигурации и рецепты изменений: [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).
