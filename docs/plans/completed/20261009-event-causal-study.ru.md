# Предрегистрированный протокол: причинное событийное исследование новостных тем (DiD / stacked DiD / TWFE / AIPW)

Статус: EXECUTED 2026-10-09 (протокол написан до первого запуска). Результаты: `docs/metrics.md` «Event causal study».
Инструмент: `cmd/eventstudy` (новый). Результат попадает в `docs/metrics.md` тем же коммитом.

## 1. Вопрос и не-цели

Сдвигают ли новостные темы, которые репозиторий уже определяет (`features.DetectEvents`, `features.DetectIncident`), доходность акции с поправкой на рынок причинно, сверх того, что мог разрешить гейт по AUC?
Это закрывает открытый пункт «вернуться к `negotiations_signal`/`sanctions_signal` после более богатого бэкфилла новостей» и даёт живому вето BUY по `incident` первое свидетельство на уровне доходности.
Не-цели: никаких изменений в `cmd/trader`, модели, порядке признаков или конфигурации. IV не запускается (нет валидного инструмента для новостной темы на MOEX; любой кандидат нарушает ограничение исключения).

## 2. Входные данные (зафиксированы)

- Новости: `data/news_history.jsonl` (`model.LoadFinanalysNewsHistory`), записи с `trust_weight > 0`,
  тикер среди 17 тикеров `config.sandbox.yaml`. Период архива 2026-04-01..2026-10-09.
- Цены: дневные свечи MOEX ISS через `backtest.NewISSSource`, неполный последний бар отброшен,
  IMOEX как рынок. Окно оценки 2025-10-01..2026-03-31 (целиком до архива);
  окно исследования 2026-04-01..последний закрытый бар.
- Темы: ОСНОВНЫЕ `sanctions`, `negotiations` (DetectEvents) и `incident` (DetectIncident).
  ПОИСКОВЫЕ `dividend`, `report`, `buyback`, `mna`. IPO/delisting/default приводятся только как счётчики.

## 3. Определение исхода и события (зафиксировано)

- Аномальная доходность `AR_it = r_it - alpha_i - beta_i * r_IMOEX,t`, close-to-close, alpha/beta по OLS
  на каждый тикер в окне оценки. Проверка устойчивости: `r_it - r_IMOEX,t`.
- Время публикации переводится в Europe/Moscow; публикация в 19:00 MSK или позже, либо в нерабочий
  день, относится к следующему торговому дню. День события t0 = этот торговый день.
- Событие = первый t0 пары (тикер, тема) хотя бы с одной помеченной статьёй; любое следующее событие той же
  пары тикер+тема в пределах 5 торговых дней отбрасывается (де-кластеризация). Для события нужны 10 чистых предыдущих дней.
- Окна: ОСНОВНОЕ CAR[0,+1] (доходность t0 по построению включает новости, учтённые внутри дня).
  ВТОРИЧНОЕ CAR[+1,+5] (дрейф после новости) и ПРЕДТРЕНД CAR[-5,-1].
- Планка круговой издержки для торгуемости: 2 x 0.0015 = 0.003 (комиссия+спред+проскальзывание на ногу, как
  в `cmd/dividendstudy`).

## 4. Оценщики (зафиксированы)

1. Событийное исследование: средний CAR по окну, 95% ДИ из бутстрэпа с ресэмплингом ДАТ событий (2000 повторов,
   seed 42), так как многие тикеры делят дату.
2. Stacked DiD (устойчив к смещению от разновременности у обычного TWFE): для каждого события стек из обработанного
   тикера плюс чистых контролей (та же тема отсутствует в [t0-10, t0+10]); DiD_e = mean_treated(post - pre)
   минус mean_controls(post - pre) для k в [-5,-1] против [0,+1]; усреднение по событиям, ДИ бутстрэпом с кластеризацией по датам.
3. TWFE: панель тикер x день, `AR_it` на дамми времени события k из {-3..+3} с фиксированными эффектами тикера и даты
   (чередующиеся проекции), SE кластеризованы по дате. Приводится рядом с (2), чтобы показать
   разрыв TWFE и stacked; коэффициенты до события (k<0) — тест предтренда.
4. Дважды робастный AIPW для ATT темы на CAR[0,+1] и CAR[+1,+5]: пропенсити = логистическая модель на
   X, модель исхода = OLS на контролях; X = AR_{t-1}, 5-дневная аномальная доходность, 20-дневная волатильность AR,
   доходность IMOEX_{t-1}, число новостей по тикеру за 5 дней, день недели. Пропенсити обрезается до [0.01, 0.99].
   Контроли исключают пары тикер-день в пределах +-5 торговых дней от собственного события той же темы. SE по
   influence-функции, агрегированной по датам.
5. Плацебо: даты событий сдвигаются внутри тикера равномерной величиной из [20, 60] торговых дней (2000 повторов);
   эмпирическая нулевая статистика DiD даёт перестановочное p-значение.
6. Проверка на уровне рынка для макро-тем: доходность IMOEX в дни, когда число статей по теме в верхнем
   дециле окна исследования, против остальных дней, ДИ бутстрэпом по датам.

## 5. Критерий приёмки (зафиксирован до чисел)

Тема «подтверждена» только если ВСЁ выполнено на ОСНОВНОМ CAR[0,+1]:
(a) N событий >= 30 минимум по 10 различным датам;
(b) stacked DiD и AIPW одного знака, каждый ДИ исключает 0;
(c) p < 0.05 с поправкой Холма по трём основным темам (перестановочное p из шага 5);
(d) ДИ предтренда CAR[-5,-1] включает 0;
(e) |эффект| > 0.003 (круговая издержка), чтобы считаться торгуемым, а не просто обнаруживаемым.
Невыполнение (a) означает «недостаточная мощность», с указанием минимально обнаруживаемого эффекта (MDE при мощности 80% по
наблюдаемой волатильности AR), но никогда не «нет эффекта». Поисковые темы приводятся, но не проходят гейт.

## 6. Известные угрозы, заявленные заранее

- Архив охватывает 6 месяцев, один режим; привязка общих новостей к тикерам шумная (VKCO — 41% записей,
  задокументированные ложные срабатывания), что смещает эффекты к 0.
- Время новостей: метки времени RSS могут отставать от первой реакции рынка, поэтому доходности t0 могут частично
  предшествовать новости; ВТОРИЧНОЕ окно [+1,+5] — то, что стратегия реально могла бы торговать.
- Знак тональности не используется: темы — флаги наличия, поэтому симметричный эффект усредняется до 0.
  Знаковый вариант допустим только как поисковый и с соответствующей пометкой.
