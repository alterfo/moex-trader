## 1. Контекст (рамка не-целей)

`docs/reports/betaregime-report.md` показывает, что реализованный P&L развёрнутого ансамбля за 18 месяцев доминируется
бетой к IMOEX: +194293 RUB всего, +129322 RUB бета-компонента, +64971 RUB избыточный; альфа на сделку t=1.469 (p=0.16, df=17),
структурная бета портфеля beta1 (бенчмарк equal-weight) t=-6.186. Стратегию сегодня
лучше всего описывает как чистую короткую ставку на IMOEX, которой случилось встретить 5/6 падающих или
плоских OOS-кварталов, то есть неотличимая альфа на сделку поверх этого.

Этот тест задаёт только вопрос: **если те же 18 сигналов торговать с нейтрализованной
чистой экспозицией (на уровне исполнения), остаётся ли статистически устойчивая дневная
альфа?** Он НЕ переобучает, НЕ перенастраивает и НЕ меняет сигнал. Результат
бинарный для гейта (0)->бифуркация.

## 2. Воспроизводимые входные данные (зафиксированы)

- Тикеры: 18 из `docs/reports/betaregime-report.md` (YDEX..POSI).

- Данные: свечи MOEX ISS (тикеры + IMOEX), как в `cmd/betaregime`.
- Бенчмарки (как в отчёте): дневная доходность equal-weight по 18 тикерам; momentum

## 3. (0a) Overlay-хедж — ОСНОВНОЙ метод

- Бета по имени bi: OLS дневных лог-доходностей close-close каждого тикера на
  дневные лог-доходности IMOEX, по всему окну (2025-04-01 -> 2026-09-17). Используется как
  измерение, не как вывод.
- Дневная совокупная экспозиция N(t) = сумма по ОТКРЫТЫМ позициям beta_i * номинал
  входа (при переоценке: position_notional_i). Позиции не меняются
  оверлеем: оверлей никогда не меняет знак или размер позиции по тикеру.
- Нога оверлея: синтетическая позиция IMOEX размером -share * N(t), share из
  {0, 0.5, 1.0} (share=0 -> нехеджированная база = воспроизводит отчёт).
  Нога ребалансируется ежедневно по закрытию.
- Издержки оверлея: комиссия 0.0005 + спред 0.0005 на оборот номинала ноги оверлея
  при каждой дневной ребалансировке (консервативно; как у ног).
- Дневной P&L оверлея = -share * N(t) * imoex_daily_return - leg_costs.
- Инвариант: НИЧЕГО в 18 тикерах не меняется; оверлей строго
  аддитивный. В основном методе перевзвешивания нет.

## 4. (0a) Вторичный — перевзвешивание (только чувствительность)

Решение sum(beta_i * w_i) = 0 по 18 сигналам. Прогон ИСКЛЮЧЁН из всех
выводов приёмки; кроме того, если какая-либо перевзвешенная позиция меняет знак
против BUY/SELL модели, прогон помечается NON_ACCEPTANCE и приводится
только как контекст.

## 5. (0b) Значимость — решающий тест

ПРИМЕЧАНИЕ (зафиксировано до прогона): оверлей — отдельная нога, поэтому альфа на сделку
ИДЕНТИЧНА с хеджем и без него по построению. Регрессия на сделку
поэтому только описательная и НЕ является условием приёмки. Различить может только дневной
ряд.

- Ряд дневной альфы e_d (для каждого уровня share s): остаток полной оконной
  дневной регрессии r_p ~ alpha + beta1*equal_weight_bench + beta2*momentum на
  скорректированных оверлеем дневных доходностях портфеля (r_p включает P&L оверлея, а
  издержки ноги входят в r_p).
- Стационарный блочный бутстрэп с геометрическими длинами блоков, средняя длина блока L
  из {5, 10, 20, 40, 60} торговых дней, N = 2000 реплик, процентильный
  ДИ(alpha_boot) = [2.5%, 97.5%]. Обоснование диапазона блоков: удержание до разворота
  создаёт зависимость порядка срока удержания (переменного, до десятков
  дней); одной длине блока доверять нельзя.
- Leave-one-quarter-out: заново подгоняется дневная регрессия и пересчитывается средняя
  альфа с поочерёдным исключением каждого из 6 OOS-кварталов. Явно включает
  просадку 2026-Q2 (-15.39%). Супертест «альфа — это один квартал».
- Приводится поквартальная разбивка альфы (описательно; как доля Q2 в альфе
  меняется от нехеджированного к share=1.0 — ключевая диагностика).

## 6. Планка приёмки (ЗАФИКСИРОВАНА, до прогона)

При share = 1.0 (полная нейтрализация):

- (A) Бутстрэп-ДИ исключает 0 на НЕПРЕРЫВНОМ ряду длин блоков, который
  ВКЛЮЧАЕТ {20, 40} (значимости при одной длине недостаточно).
- (B) Leave-one-quarter-out: средняя альфа сохраняет знак при всех шести исключениях.
- (C) Согласие с нехеджированным рядом не требуется; нехеджированный служит для
  декомпозиции, решает хеджированный.

A И B обе выполнены -> альфа переживает бета-нейтральное исполнение -> переход к
                      (1) варианту с управляемой бетой (обратно-волатильностный размер и
                      настраиваемый max_net_exposure как ОТДЕЛЬНЫЕ оси; никогда не
                      смешиваются).
Любая не выполнена  -> альфа — остаточная бета/шум -> бифуркация: продуктовое
                      решение между управляемой бета-короткой позицией и перенаправлением ресурсов
                      на (2) исследование событийного дрейфа с event-study и
                      гейтом по прокси спреда.
Вторичное перевзвешивание (раздел 4) никогда не учитывается в приёмке.
