# AlgoPack composite alpha and cost-aware execution: a new model class, spent once (2026-10-23)

Status: DONE 2026-10-23 (English only): verdict run once on the realtime window, numbers in `docs/metrics.md` 8.20, outputs in `artifacts/algopack-alphafit/`; results verified number-for-number by the Reviewer, wording and forward-rule power amendments applied. Design agreed with the Reviewer in the model-class exchange of 2026-10-23.

## Why this plan

Nine earlier plans tested single scalar features or a GBM on ten columns. Economically they all land near zero net. The owner asked for new mathematical models. The two levers that remain are (A) signal combination: a regularised composite of all about 77 AlgoPack daily features, and (C) cost-aware execution: a Garleanu-Pedersen partial-adjustment book instead of a daily-rebalanced quintile book. The Reviewer's ranking (C first, A second) and its objections are incorporated: rank-demeaned inputs, purged and embargoed walk-forward, the model class fixed a priori, hyperparameters and the trade rate fitted on the exploration window only, the realtime window spent exactly once, a shuffled-feature placebo, and the economic gate as the verdict. Dropped: sequence models, MLP, optimal-transport features, quantile regression as an alpha source (sample too small, regenerated history does not transfer); no torch. Ridge and elastic net are written in Go (`cmd/alphafit`); the project's Python GBM path is not used.

## Data and features

`cmd/flowscan -mode matrix` (ai-box, 2026-10-23): one row per ticker-day for the point-in-time top-100 by 60-day median value, 163709 rows, 1644 dates 2020-01..2026-10-20 (SYSTIME rule from 2025-01-01 as in the earlier plans), `YNDX`/`TCSG` aliased, backward and forward close-to-close returns and the universe mean return per date, and the daily base columns of the 100-hypothesis library plus eight new microstructure columns (VPIN-style absolute volume imbalance, Kyle-type slope of bar return on bar imbalance, flow-return correlation, flow autocorrelation, realised skewness, book-imbalance autocorrelation, intraday profile tilt, cumulative-imbalance slope; bars up to 18:30). Price levels, the evening and morning-session columns are excluded (era-dependent), and so are `ValDay` (it sums the whole main session up to 18:50) and the closing-auction imbalance `AucA1` (18:40-18:50): they embed the 18:30-18:50 window and are not implementable at the close, so every remaining column uses bars up to 18:30. Two derived columns, the "unexpected" A1 and A2 (z-score against the same ticker's previous 20 days, which is the innovation of daily imbalance). Result: 75 AlgoPack features (the startup log of `cmd/alphafit` prints the count) plus three control ranks (backward 1-, 5-, 20-day returns, always in the model so that the composite is incremental to reversal and momentum). Each feature is rank-scaled to [-0.5, 0.5] within the date over the names that have it (missing = 0). The target is the rank within the date of the 10-day forward abnormal return (close of d to close of d+10 minus the equal-weighted top-100 mean), dividend days dropped; the 5-day target is not used.

## Models (fixed a priori)

- **Composite**: the average of a ridge and an elastic net (alpha 0.5) on all 80 inputs, no intercept (inputs and target are within-date centred). Hyperparameters from the exploration window only.
- **Baseline**: ridge on A2 plus the three controls (lambda 0.001), same machinery.
- **Placebo**: the same composite trained and scored on feature vectors permuted across tickers within each date (five seeds 20261023..20261027); the placebo keeps every date-level moment of every feature and removes the cross-sectional pairing.
- **Realtime-only arm (descriptive, same single run)**: the composite and the baseline trained only on realtime rows (training starts 2025-01-03, blocks 3-7), reported next to the primary arm, never a pass condition.
- **Walk-forward**: expanding window from 2020-04-01; the training set of a test block holds only dates at least 11 trading days before the block start (label span 10 days, purge and embargo in one rule). Quarterly blocks for the verdict (2025-01-03..2026-10-16, seven blocks as in the earlier plans), half-year blocks for the exploration (2022-07..2024-12).

## Exploration results (regenerated history, selection surface only)

Ridge lambda (times n) over {0.003, 0.01, 0.03, 0.1, 0.3, 1}: mean IC 0.1328 at 0.003 down to 0.1167 at 1; elastic net lambda over {0.0002 .. 0.004}: best 0.1326 at 0.001. Chosen: ridge 0.003, elastic net 0.001 (frozen file `alphafit-frozen.json`). Mean daily IC against the 10-day abnormal rank over 2022-07..2024-12: composite 0.1335, A2 plus controls 0.1087. The exploration was run twice: before and after excluding `ValDay` and `AucA1` (the Reviewer's soft-leak finding); the composite IC moved from 0.13351 to 0.13348, so the measured size of the soft leak is 0.00003, and the chosen hyperparameters and trade rate are unchanged. Probes on the exploration window: the single-feature mean IC is led by the A2 family (A2H2 0.1105, A2Late 0.1096, A2 0.1046, ImbVol 0.1026, LevAsym 0.0936), the composite with every feature lagged by one date has IC 0.1139 and with five dates 0.0885 (A2 alone 0.0945 and 0.0838), i.e. the exploration signal is a persistent cross-sectional characteristic, not a one-day artefact. Dollar-neutral top-minus-bottom quintile book (inverse-volatility legs, 0.15% per side, borrow 17% a year): gross 0.382% per day, net per day 0.0579% with daily rebalancing and 0.1142% with partial adjustment at rate 0.33 (rates 1, 0.5, 0.33, 0.2, 0.1, 0.05 gave 0.058, 0.111, 0.114, 0.104, 0.080, 0.053); A2 alone 0.044% daily and 0.091% at rate 0.33. Chosen trade rate 0.33. The exploration IC is large because the window is regenerated history, where the A2 effect was strong (plan 20261022: gross +0.18% per day long-only); the exploration-to-realtime IC drop is reported as a headline number.

## Verdict (frozen form, to be run once on the realtime window)

Realtime window: feature dates 2025-01-03..2026-10-16, halves split 2026-01-05, training expanding through the exploration window and the earlier verdict blocks. Date-block bootstrap (block 10 dates, 5000 draws, seed 20261022).

1. **Signal statistic**: mean daily out-of-fold IC of the composite minus that of the baseline; pass needs the mean positive, the bootstrap 95% interval above 0, both halves positive, and the composite IC above the placebo IC with the difference's interval above 0 in at least four of five placebo seeds.
2. **Economic gate** (the verdict for calling it a real edge): the dollar-neutral long-short quintile book of the composite, inverse-volatility legs, 0.15% per side on the turnover of each leg, 17% a year borrow on the short notional (25% reported as a stress), daily rebalanced; pass needs the mean daily net with the bootstrap interval above 0 in both halves, and the placebo books' mean daily net not positive. The annualised level is reported against the key rate as context, not as a criterion (financing roughly cancels in a dollar-neutral book).
3. **Execution comparison**: the partial-adjustment book (rate 0.33) against the daily-rebalanced book of the same composite, difference of daily nets, bootstrap interval above 0.
4. A pass of 1 and 2 is a lead with a frozen forward rule (models trained through the last verdict date, one evaluation after 60 forward dates, no retraining); a pass of 3 without 2 is an execution finding. Nothing enters the live path.

## Honest expectations

The A2 family weakened in realtime (net halves +0.066% / +0.033%, F1 hedged second half negative), the 100-hypothesis scan found 0 of 28, and the short leg carries the round 3 gate with an unmeasured borrow. The prior of passing the economic gate is low-medium; a null is an expected, recorded result. The realtime window is spent for individual features; this is a new model class evaluated once, with a placebo that absorbs class-level inflation.

## Result (realtime verdict, run once, 2026-10-23)

Frozen parameters: ridge lambda 0.003, elastic net lambda 0.001 alpha 0.5, trade rate 0.33. Output `artifacts/algopack-alphafit/alphafit-verdict.txt` (a second run with extra descriptive printing for the partial-adjustment book is identical in every previously printed number, `alphafit-verdict-run1.txt` is the first; the program is deterministic).

- **Signal statistic: PASS.** Mean daily out-of-fold IC against the 10-day abnormal rank: composite (blend) +0.0957 (Newey-West t +5.87, bootstrap 95% [+0.0693, +0.1294], halves +0.0853 / +0.1092), ridge +0.0970, elastic net +0.0915, baseline A2 plus controls +0.0589 ([+0.0389, +0.0778]). Composite minus baseline +0.0368 (t +2.51, [+0.0147, +0.0663], halves +0.0431 / +0.0286). The five placebo composites have IC between -0.0042 and +0.0052 (none significant), and the composite minus placebo difference has an interval above 0 in 5 of 5 seeds (differences +0.0905..+0.0999). Exploration-to-realtime IC drop (headline): composite 0.1335 to 0.0957 (-28%), A2 0.1087 to 0.0589 (-46%).
- **Economic gate (daily-rebalanced dollar-neutral quintile book, 0.15% per side, borrow 17% a year): FAIL.** Composite net -0.0650% per day (bootstrap [-0.149%, +0.027%], halves -0.102% / -0.018%), gross +0.282% per day, turnover 1.864 per day (costs of 0.280% a day absorb the gross), annualised net -16.4%; at 25% borrow -0.097% per day. A2 alone -0.100% per day ([-0.154%, -0.039%]). The five placebo books lose -0.54% to -0.60% per day (random trading). The gate required the interval above 0 in both halves; it is not met.
- **Execution comparison: PASS.** The partial-adjustment book (rate 0.33): turnover 0.629 per day, gross +0.187% per day, net +0.0298% per day at 17% borrow (bootstrap [-0.048%, +0.114%], halves +0.024% / +0.037%, annualised +7.5% on the long-leg notional), +0.0002% per day at 25% borrow ([-0.078%, +0.084%]). Net of the partial-adjustment book minus the daily-rebalanced book: +0.0950% per day ([+0.0590%, +0.1310%], halves +0.126% / +0.055%); for A2 alone +0.0840% per day. The partial-adjustment composite net is positive in both halves but its interval includes 0, and it vanishes at 25% borrow.
- **Descriptive arm, training on realtime rows only (blocks 3-7):** composite IC +0.0846 (t +3.65, [+0.0480, +0.1325], halves +0.0718 / +0.0932) against A2 +0.0299 ([-0.0042, +0.0606]); the daily-rebalanced net is -0.200% per day.
- **Registered reading** (pass of 1 and 2 would be a lead): the economic gate fails, the execution comparison passes, therefore this is an **execution finding with a passing signal statistic**, not an economic edge. Remaining facts for the owner: the composite is a real cross-sectional forecast of 10-day abnormal returns in realtime data (IC about 0.10, A2 alone 0.06), the best book is worth about 7.5% a year at 17% borrow and nothing at 25%, which is below the key rate of 14-21% and inside the uncertainty of an unmeasured borrow rate.

## Forward rule (frozen 2026-10-23, before any forward date exists)

Models: `artifacts/algopack-alphafit/alphafit-models-20261023.json` (also on the ai-box in `frozen/`), trained on feature dates 2020-04-02..2026-10-07 (159708 rows, 78 inputs: ridge, elastic net, A2 baseline coefficients), SHA-256 `793bf125b38b2022dae53021f5185032bb464c506ce2f507d8fb39fb4a2f8892`; hyperparameters in `alphafit-hyper-20261023.json` (trade rate 0.33). Evaluation once, by the owner or on the owner's instruction, never by an automatic job, after 60 forward feature dates with matured 10-day outcomes (from 2026-10-22; about 2027-02-05) with `cmd/alphafit -mode forward -from 2026-10-22` on a matrix rebuilt by `cmd/flowscan -mode matrix` from the refreshed AlgoPack data (the daily job `scripts/algopack-daily.sh` accrues it); a forward date counts only if the rebuilt matrix produces rows for it, a missing day is never backfilled after the evaluation date, and no day is added afterwards. Accepted as confirmed if (a) the mean IC of the composite minus the baseline is positive with the date-block bootstrap 95% interval above 0 (minimum detectable at 60 dates about +0.07, since the verdict's interval half-width of about 0.026 over 450 dates scales by about 2.7; the verdict's +0.037 would have to roughly double), and (b) the partial-adjustment book mean daily net at 17% borrow is reported with its interval and the minimum detectable effect of about +0.22% per day (the verdict's half-width of 0.081% scales to that), so (b) is not a confirmation condition by itself and a null on it is uninformative, not a refutation. The 25% borrow result and the realtime-only-trained arm are reported next to the frozen arm. One pre-specified rule; a weaker result is reported as it is and the window is not extended. Before any economic reading, `cmd/borrowmeasure` is run: the entire economic value lives between the 17% and the 25% borrow rate (7.5% a year against nothing), and the 17% figure is an unconfirmed secondary-source REPO quote. The rebuilt matrix refetches the last days, so the frozen coefficients meet slightly refreshed features near the training boundary; this is accepted by design. No retraining. Nothing enters the live path without a separate owner decision, which would also need the real short-borrow rate.

## Composite shadow recorder (added 2026-10-25, owner's order of work)

`scripts/composite-shadow.sh` (launchd template `scripts/launchd/com.oleg.moex-trader.compositeshadow.plist`, 00:50 Moscow, after the AlgoPack daily fetch at 00:20; **not loaded**, the owner enables it with `launchctl load`) syncs the last seven days of the AlgoPack files to the ai-box, rebuilds the matrix there, and scores the frozen models (SHA-256 `793bf125...`) with the new mode `cmd/alphafit -mode shadow`, writing one file per run date, `data/shadow-composite/scores-<as-of date>.csv` (date, ticker, liquidity rank, composite score, A2 baseline score, the daily-rebalanced target weight). It computes no statistic and no return: it only logs point-in-time scores as they were computable on the as-of date (the last four fetched days are refreshed by the daily job, so successive files can differ slightly for recent dates; keeping every vintage is the point). The forward read of this plan still uses `-mode forward` once at the evaluation date; the recorder never replaces or pre-empts it. The first manual run (2026-10-25) wrote 99 names for each of 2026-10-22 and 2026-10-23. The four wave-3b base columns are excluded from the default feature set (`-with3b` restores them), so the matrix rebuilt by the current `flowscan` still gives the 75 features the frozen models expect.
