## Кандидаты на перенос в `completed/`

Все выполненные планы перечислены в `docs/metrics.md` и `docs/knowledge/*` полными путями `docs/plans/<имя>`, поэтому перенос требует правки этих ссылок в том же коммите. Не сделано 2026-10-18, потому что `docs/metrics.md` в этот момент правила вторая сессия (правило AGENTS.md про отсутствие параллельных правок). Делать одним коммитом после того, как она закоммитит `docs/metrics.md`: `git mv` девяти файлов из таблицы выше и замена путей во всех ссылающихся файлах.
