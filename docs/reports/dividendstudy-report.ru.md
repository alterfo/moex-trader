# Событийное исследование захвата дивидендов (2) — ОТКЛОНЕНО 2026-09-25

Предрегистрация: `docs/plans/completed/20260925-event-driven-dividend-drift.md`.
Инструмент: `cmd/dividendstudy`; данные: `data/dividends.jsonl` (123 события 2021-2027
из T-Invest `GetDividends`, 65 в окне исследования 2024-01-01..2026-12-19).

## Вердикт

**Отклонить.** Предрегистрированный критерий приёмки (A)+(B) не выполняется на требуемом
смежном подмножестве смещений, содержащем {-2,-3,-5}, при ОБОИХ налоговых соглашениях.
Захват дивидендов на этих 18 именах не годится для развёртывания как источник дохода (2).

## Механика (почему)

- Средний gap ratio **-0.97** (OPEN на экс-дату примерно на полный дивиденд ниже
  закрытия LastBuy): рынок закладывает падение на экс-дату практически полностью.
- Избыток над IMOEX при основном смещении k=-3: -0.0063 (налог 0.13) / +0.000063
  (налог 0), ДИ [-0.022, +0.010] / [-0.0165, +0.0165] — неотличим
  от нуля; исключение по одному не проходит по всем четырём осям (тикер/сезон/год/волна).
- Смещения -5 и -2: ДИ содержит 0; -5 не проходит по году и волне, -2 не проходит
  по сезону, году и волне (оба налоговых соглашения).
- Только смещение -1 (покупка по закрытию T-1, продажа по закрытию экс-даты) имеет ДИ, исключающий 0:
  избыток +0.0006 (налог 0.13) / +0.0071 (налог 0), ДИ [0.0008,+0.0151] при налоге 0.
  Оно ВНЕ предрегистрированного подмножества приёмки, которое требует
  смежного набора, содержащего {-2,-3,-5}; одно удачное смещение ничего
  не решает (правило протокола).
- Подкритерий (DividendNet брутто против нетто, семантика LastBuy/record T+1) закрыт
  не полностью; вердикт устойчив к допущениям, поэтому не может изменить исход.

## Покрытие

65 событий, 9 волн (2024/2025/2026 x SPRING/AUTUMN/OTHER), 80% вне

## Дальнейшие шаги

Дальнейшей работы по (2) нет без НОВОЙ гипотезы и новой предрегистрации.
Источник дохода возвращается к (1): 2-3x целевой номинал с лимитом чистой экспозиции
`max_net_exposure` (просадка без хеджа 3.71%/4.43% сейчас превышает порог kill switch 3%
при 2x/3x), с проверкой на префлайте со стрессом займа.
